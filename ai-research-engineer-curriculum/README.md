# AI / CS Research Engineer Curriculum — OSINT Resource & Mastery Layer v1.1

This directory mirrors the public, source-safe parts of the user's long-term AI/CS research-engineering study plan.

## Goal
Progress from computing foundations through mathematics, statistics, computer systems, platform engineering, cybersecurity, ML/deep learning, foundation models, GPU/AI systems, post-training, retrieval, agents, multimodal/robotics/AI4Science, and PhD-style research practice.

The mastery rule is:

**Build it → break it → diagnose it → benchmark it → explain it → defend it.**

AI coding/research assistants are allowed, but the learner must demonstrate code ownership, independent evaluation, and the ability to identify incorrect AI output.

## Canonical artifacts
The full workbook is stored in Google Drive. This GitHub branch mirrors the public training/repository/mastery methodology and can later become a dedicated curriculum repository.

## Files
- `distillation-niche-track.md` — multi-source knowledge-distillation and small specialist-model track.
- `mastery-standard.md` — evidence required before a course is marked mastered.
- `osint-source-index.md` — curated starting sources across the curriculum.

## Research policy
Prefer, in order:
1. official university courses and labs;
2. canonical papers and authors' repositories;
3. official open-source project documentation;
4. established training organizations;
5. high-quality paid/Udemy material as structured supplements;
6. community tutorials only when independently validated.

All fast-moving resources should be re-reviewed before use.
