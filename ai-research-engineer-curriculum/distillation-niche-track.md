# Distillation & Niche AI Systems Track

DeepSeek is one case study, not the curriculum. The track deliberately includes Google, Microsoft, NVIDIA, Hugging Face, Meta, Apple, SentenceTransformers and broader academic work.

| ID | Topic | Primary source | Repository | Mastery project |
|---|---|---|---|---|
| KD-01 | Classical soft-target knowledge distillation | [Hinton, Vinyals & Dean — Distilling the Knowledge in a Neural Network](https://arxiv.org/abs/1503.02531) | [pytorch/tutorials](https://github.com/pytorch/tutorials) | Teacher ResNet/CNN → compact student on CIFAR-100; compare hard labels, KD, and temperature sweep. |
| KD-02 | Transformer representation and attention distillation | [TinyBERT / MiniLM](https://arxiv.org/abs/1909.10351) | [huggingface/transformers](https://github.com/huggingface/transformers) | BERT-base teacher → 6-layer student; compare logits-only vs hidden-state vs attention losses. |
| KD-03 | Rationale / step-by-step distillation | [Google — Distilling Step-by-Step!](https://research.google/pubs/distilling-step-by-step-outperforming-larger-language-models-with-less-training-data-and-smaller-model-sizes/) | [google-research/distilling-step-by-step](https://github.com/google-research/distilling-step-by-step) | Generate rationale+label data from a teacher; train student with label-only vs rationale multi-task supervision. |
| KD-04 | Generative reverse-KL distillation | [Microsoft Research — MiniLLM](https://www.microsoft.com/en-us/research/publication/knowledge-distillation-of-large-language-models/) | [microsoft/LMOps](https://github.com/microsoft/LMOps) | Compare forward KL and reverse KL on instruction generation. |
| KD-05 | On-policy / Generalized Knowledge Distillation | [Hugging Face TRL DistillationTrainer / agent distillation curriculum](https://huggingface.co/blog/huggingface/train-agents) | [huggingface/trl](https://github.com/huggingface/trl) | Compare SFT, offline teacher-data KD, and on-policy distillation for a 0.5B–1.5B student. |
| KD-06 | Pruning + distillation / Minitron | [NVIDIA Minitron pruning and distillation](https://developer.nvidia.com/blog/?p=87164) | [NVIDIA/Model-Optimizer](https://github.com/NVIDIA/Model-Optimizer) | Prune layers/MLP/heads of a small open transformer, then recover quality using KD. |
| KD-07 | Speech-model distillation | [Distil-Whisper](https://huggingface.co/distil-whisper) | [huggingface/distil-whisper](https://github.com/huggingface/distil-whisper) | Distill a Whisper teacher into a smaller ASR student. |
| KD-08 | Embedding and reranker distillation | [Sentence Transformers Model Distillation](https://sbert.net/examples/sentence_transformer/training/distillation/README.html) | [UKPLab/sentence-transformers](https://github.com/UKPLab/sentence-transformers) | Distill a large embedding/reranker teacher into a compact domain retrieval model. |
| KD-09 | Vision distillation | [DeiT](https://arxiv.org/abs/2012.12877) | [facebookresearch/deit](https://github.com/facebookresearch/deit) | CNN/ViT teacher → smaller ViT; compare output KD and distillation-token approach. |
| KD-10 | Multimodal / VLM distillation | [VLM KD literature search](https://arxiv.org/search/?query=vision-language+knowledge+distillation&searchtype=all) | [HoangTran223/Awesome-Knowledge-Distillation-of-VLMs](https://github.com/HoangTran223/Awesome-Knowledge-Distillation-of-VLMs) | CLIP/VLM teacher → compact image-text retrieval/classification student. |
| KD-11 | Small-model architecture engineering | [Meta MobileLLM](https://github.com/facebookresearch/MobileLLM) | [facebookresearch/MobileLLM](https://github.com/facebookresearch/MobileLLM) | Fixed-parameter architecture study: deep-thin vs baseline under same budget. |
| KD-12 | Synthetic textbook data and small specialist models | [Microsoft — Textbooks Are All You Need](https://www.microsoft.com/en-us/research/publication/textbooks-are-all-you-need/) | [microsoft/PhiCookBook](https://github.com/microsoft/PhiCookBook) | Build a synthetic textbook/exercise pipeline and train/adapt a compact model for a verifiable skill. |
| KD-13 | Transparent efficient model training | [Apple OpenELM](https://machinelearning.apple.com/research/openelm) | [apple/corenet](https://github.com/apple/corenet) | Reproduce a small layer-wise scaling experiment and specialist adaptation. |
| KD-14 | Domain-adaptive / task-adaptive pretraining | [Don't Stop Pretraining](https://arxiv.org/abs/2004.10964) | [huggingface/transformers](https://github.com/huggingface/transformers) | DAPT/TAPT a compact base model on a licensed domain corpus, then compare SFT and KD variants. |
| KD-15 | Specialist routing / model cascades | [RouteLLM](https://github.com/lm-sys/RouteLLM) | [lm-sys/RouteLLM](https://github.com/lm-sys/RouteLLM) | Route easy requests to a small specialist and hard/OOD requests to frontier fallback. |
| KD-16 | Multi-adapter specialist fleet | [S-LoRA / Punica concepts](https://arxiv.org/abs/2311.03285) | [huggingface/peft](https://github.com/huggingface/peft) | Train three domain LoRA specialists on one base and serve/rout them. |
| KD-17 | Niche AI System Factory capstone | Use all prior sources; DeepSeek is comparative only | [huggingface/trl](https://github.com/huggingface/trl) | Gold eval → general model → RAG → adapted model → distilled student → router/fallback → safety/monitoring. |
